# poc-wiki — local fixture wiki

This directory mirrors the structure of a real Marginalia wiki, with
the addition of a `raw/` subdirectory that production splits out into
a separate path (`~/wiki-raw/`).

## Layout

| Subdir / file | Role | Production analogue | Read by |
|---|---|---|---|
| `raw/` | **Inbox** — unprocessed inputs to ingest (markdown, PDF, PNG). | `~/wiki-raw/` (the `WIKI_RAW_PATH` env var) | NB 02 ingest, NB 04 multi-modal ingest |
| `sources/` | **Wiki content** — processed `SourcePage` files (frontmatter + body). | The wiki content repo's `sources/` dir | NB 05 cross-source synthesis (and onward) |
| `purpose.md` | Wiki-level scope rules. | Same path in the wiki repo | `engine.models.wiki_config.MarginaliaConfig.load()` |
| `AGENTS.md` | Wiki-level style + terminology rules. | Same path in the wiki repo | Same loader |

## Why this split matters

`raw/foo.md` and `sources/foo.md` look superficially similar — both are
markdown files — but they sit on opposite sides of the ingest pipeline:

```
raw/clean.pdf  ──► extract_pdf  ──► analyze_source  ──► synthesize_page  ──► sources/marginalia-engine-architecture-and-model-selection.md
```

The frontmatter is the tell: `sources/*.md` files have `type: source`,
populated `sources` ref lists, validated dates, etc. They validate as
`SourcePage` Pydantic objects. The `raw/*.md` files are unstructured.

## Don't conflate two `raw` concepts

Design.md uses `raw` in two distinct ways. The PoC only models the
first one:

| Term | Meaning | Modeled in the PoC? |
|---|---|---|
| `~/wiki-raw/` | Transient *inbox* outside the wiki repo (`WIKI_RAW_PATH`). | Yes → `poc-wiki/raw/` |
| `sources/raw/` | In-wiki *durable archive* of original files without an upstream home (PDFs, manual web clips). | No (PoC has no upstream-home distinction yet) |

## Regenerating the `sources/` fixtures

Three of the five `sources/*.md` files are auto-generated by running
ingest on the corresponding `raw/*` inputs. Re-run anytime (idempotent):

```bash
uv run python notebooks/_ops/build_source_pages.py
```

The remaining two (`apollo-q2.md`, `apollo-q3.md`) are hand-curated
to be deliberately contradictory for NB 05's edge-case cell. **Do not
regenerate these.**
